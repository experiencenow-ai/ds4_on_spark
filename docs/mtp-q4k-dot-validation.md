# Q4_K dot math validation (llama.cpp fixture)

This repo uses `antirez/ds4` as the CUDA execution oracle for the DeepSeek V4 Flash MTP sidecar. The DS4-tuned sidecar uses routed MoE expert weights in `Q4_K`, so any CUDA fallback path must match ggml’s `Q4_K` dequantization math closely enough that intermediate tensors can be compared against the oracle.

## What is validated

- `scripts/verify_antirez_ds4_q4k_dot_math.py` validates a host-side translation of ggml `dequantize_row_q4_K` + dot-product against:
  - a second, independently-written translation matching the CUDA helper used by the DS4 patch notes, and
  - a pinned fixture generated from **real** `ggml-org/llama.cpp` `dequantize_row_q4_K` at `refs/tags/b9110`.

The pinned fixture file is:

- `fixtures/quant/q4k_llamacpp_b9110_rowdot_fixture.json`

## Run the check (no CUDA required)

```bash
python3 scripts/verify_antirez_ds4_q4k_dot_math.py --fixture fixtures/quant/q4k_llamacpp_b9110_rowdot_fixture.json
```

There is also a small unittest gate:

```bash
python3 -m unittest tests/q4k_llamacpp_fixture_test.py
```

## Fixture provenance

The fixture is intended to be an **independent** oracle:

- The `dot` values are generated by a C tool compiled against `ggml-org/llama.cpp` `b9110`, calling `dequantize_row_q4_K(...)` from ggml.
- `block_hex` is the raw `block_q4_K` byte blob (144 bytes) generated via an `xorshift32` byte stream (so it’s deterministic and does not depend on libc RNG).
- `x` is *not* stored; it is regenerated from `seed_x` using the same deterministic mapping used by `scripts/verify_antirez_ds4_q4k_dot_math.py`:
  - `t = (u & 0x00FFFFFF) / 2^24`
  - `x = (t * 6) - 3` (so `x ∈ [-3, 3)`)

The fixture JSON includes the upstream repo/ref/commit it was generated from.

## Regenerating the fixture (gated)

To reproduce or refresh the fixture from the upstream ggml implementation (requires a working C toolchain + CMake), use:

```bash
ALLOW_FETCH=1 ALLOW_BUILD=1 \
scripts/generate_q4k_llamacpp_rowdot_fixture.sh \
  --ref b9110 \
  --vectors 16 \
  --out fixtures/quant/q4k_llamacpp_b9110_rowdot_fixture.json
```

Notes:

- The script is gated (defaults to `ALLOW_FETCH=0`, `ALLOW_BUILD=0`) to avoid accidental large builds in automation loops.
- If you change the `--vectors` count or the generation parameters, update the fixture filename and any docs that refer to it.
